# \## Задание

# Написать программу, которая вычисляет среднее значение трёх чисел.

# 

# \## Как работает

# Пользователь вводит три числа через пробел (или каждое с новой строки).

# Программа парсит их как `float64`.

# Функция `average` возвращает среднее арифметическое.

# Результат выводится с точностью до двух знаков.
