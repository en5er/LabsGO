# Лабораторная работа 1 — Вариант 6

## Задание

Написать программу, которая вычисляет среднее значение трёх чисел.

## Как работает

1. Пользователь вводит три числа через пробел (или каждое с новой строки).
2. Программа парсит их как `float64`.
3. Функция `average` возвращает среднее арифметическое.
4. Результат выводится с точностью до двух знаков.
