\# Лабораторная работа 2



В работе 6 заданий, все в одном файле laba02.go.



\## Задания



1\. Проверка числа на чётность/нечётность.

2\. Функция возвращает Positive / Negative / Zero.

3\. Вывод чисел от 1 до 10 циклом for.

4\. Функция для длины строки.

5\. Структура Rectangle и метод для площади.

6\. Среднее значение двух целых чисел.



\## Как работает



Ввод через bufio, числа парсим через strconv.Atoi. Для задания 6 использую

strings.Fields, чтобы вытащить два числа из одной строки.



В 6-м задании важно привести сумму к float64, иначе деление будет целочисленным

и для 1 и 2 получится 1, а не 1.5.



\## Запуск



```bash

go run laba02.go

```
