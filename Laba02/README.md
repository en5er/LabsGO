# Лабораторная работа 2 — Вариант 6

## Задание
Написать функцию, которая принимает два целых числа и возвращает их среднее значение.

## Как работает
Пользователь вводит два целых числа через пробел.
Программа парсит их как `int`.
Функция `average` возвращает среднее арифметическое в виде `float64`.
Результат выводится с точностью до двух знаков.

```bash
go run laba02.go
```
