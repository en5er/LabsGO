\# Лабораторная работа 3



Тут 6 заданий. Впервые нужны отдельные пакеты, поэтому в папке Laba03

лежат ещё две подпапки — mathutils и stringutils.



\## Задания



1\. Пакет mathutils с функцией факториала.

2\. Использовать mathutils для факториала введённого числа.

3\. Пакет stringutils с функцией переворота строки.

4\. Массив из 5 целых чисел.

5\. Срез из массива, добавление и удаление элементов.

6\. Срез строк, найти самую длинную.



\## Структура



\- laba03.go — основная программа

\- mathutils/mathutils.go — пакет с факториалом

\- stringutils/stringutils.go — пакет с переворотом строки



\## Как работает



Пакеты лежат рядом с laba03.go, импортируются через labsgo/Laba03/mathutils

и labsgo/Laba03/stringutils. Факториал считается циклом, переворот строки —

через \[]rune, чтобы русские буквы не превращались в кракозябры.



В 5-м задании срез делается из массива, потом append добавляет 60 и 70,

а удаление элемента с индексом 2 — через append среза до и после этого элемента.



\## Запуск

```bash
go run ./Laba03

```

```bash
go run laba03.go
```
