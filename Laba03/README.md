# Лабораторная работа 3

Тема: пакеты, массивы, срезы.

## Задания

1. Создать пакет mathutils с функцией для вычисления факториала числа.
2. Использовать mathutils для вычисления факториала введённого числа.
3. Создать пакет stringutils с функцией переворота строки.
4. Создать массив из 5 целых чисел и вывести его.
5. Создать срез из массива, добавить и удалить элементы.
6. Создать срез строк и найти самую длинную строку.

## Структура

- laba03.go — основная программа
- mathutils/mathutils.go — пакет с факториалом
- stringutils/stringutils.go — пакет с переворотом строки

## Как работает

Пакеты лежат рядом с laba03.go и импортируются через labsgo/Laba03/mathutils
и labsgo/Laba03/stringutils.

Факториал считается циклом, переворот строки — через []rune, чтобы русские
буквы не превращались в кракозябры.

В 5-м задании срез делается из массива, потом append добавляет 60 и 70,
а удаление элемента с индексом 2 — через append среза до и после этого элемента.

## Запуск

```bash
go run ./Laba03
```
